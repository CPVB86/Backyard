# AvianVisitors presentation provenance

The view structure, count-weighted silhouette packing, pose selection, contour
labels, sliding sheets, staggered entrances, statistics layout and postage-stamp
atlas in this module are adapted from the AvianVisitors frontend in
`CPVB86/AvianVisitors`, itself derived from `Twarner491/AvianVisitors`.

The source repository carries the Creative Commons Attribution-NonCommercial-
ShareAlike 4.0 license in its `LICENSE`. No historical bird images, masks,
dimension tables, fonts, detector code, API code, databases or generated output
are copied here. All species data and visual assets are supplied at runtime by
Backyard observations and the central Backyard Generator store.
